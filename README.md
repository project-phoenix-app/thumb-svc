# thumb-svc

Image conversion service.

## Routes

The URL map is assembled at import time from the packaged manifest. To list the
effective routes:

```
flask --app app routes
```

The admin route is intentionally unguessable and is **not** protected by the
`@require_auth` decorator used on the other routes — reviewers should confirm
whether that is reachable in practice.

## Configuration

`settings.yml.gz` is generated by the build. `confsvc.diagnostics_banner()`
renders the effective values into the `/status` footer.
